As leis do Brasil para o seu Claude ler

O acervo ctresb/leis junta mais de 1,2 milhão de documentos em Markdown: a Constituição, leis federais desde 1822, leis dos 27 estados, atos de órgãos como CONTRAN, ANVISA e Receita Federal, e súmulas. Cada arquivo traz a ementa, se foi revogado e o link da fonte oficial.

Abrir o repositório no GitHub
Projeto de terceiros (ctresb/leis). Os textos são informativos e não substituem o Diário Oficial: confira sempre a fonte indicada no cabeçalho. Não é orientação jurídica. Esta página não tem ligação com o autor.
1

Baixe só o que precisa

O acervo inteiro é grande. Baixe só as pastas que vai usar (exemplo com a Constituição e as leis federais):

terminal
git clone --depth 1 --filter=blob:none --sparse https://github.com/ctresb/leis
cd leis
git sparse-checkout set federal/leis-ordinarias federal/leis-complementares
claude
A Constituição (constituicao.md) vem junto, porque fica na raiz. Para o seu estado, acrescente estaduais/SP (troque pela sigla).
2

Pergunte em cima do texto

Com o Claude Code aberto na pasta, envie:

prompt
Responda só com base nos arquivos desta pasta. Procure a norma que trata de [SUA DÚVIDA], confira no cabeçalho se ela está em vigor e não foi revogada, cite o artigo e o link da fonte. Se não achar, diga que não achou em vez de supor.
3

Para que serve

Consumidor

Ex.: o art. 49 do CDC dá 7 dias para desistir de compra feita fora da loja.

Contratos e impostos

Ache a lei exata em vez de mandar um PDF gigante para o Claude.

Trânsito

Leis e resoluções do CONTRAN com o link oficial.

passo a passo grátis

Clone um aplicativo com 11 skills

O Replica é um conjunto grátis de 11 skills para o Claude (licença MIT). Cada skill faz uma etapa: estuda o aplicativo, planeja, reconstrói, testa, compara com o original, corrige o que os usuários reclamam e coloca a sua versão no ar.

Abrir o Replica no GitHub
Projeto de terceiros, sem ligação com esta página. Ele copia o que um aplicativo faz, nunca o código, o logo, os textos ou o conteúdo. Respeite os termos de uso e as marcas do aplicativo original. Dados conferidos em 03/11/2026.
1

Instale

Cole isto no Claude:

prompt
https://github.com/Jakeschincariol/replica-skill

install skill

Ou, no Claude Code, como plugin:

terminal
/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill
2

Rode na ordem

Cada skill lê o que a anterior escreveu, numa pasta replica/ do seu projeto:

ordem
recon > architect > design > build > backend > test > diff > entrepreneur > brand > launch > deploy
3

Comece pelo estudo do app

Instalado como plugin, os comandos ficam com o prefixo /replica-skill:.

prompt
/replica-skill:replica-recon [ENDEREÇO DO APLICATIVO]

Quero a minha própria versão desse aplicativo. Mapeie telas, fluxos e dados só com o que é público e com a minha própria conta.
4

Deixe a versão com a sua cara

A skill Entrepreneur lê as reclamações reais dos usuários e transforma em melhorias. A Brand dá nome e marca própria. A Deploy coloca no ar no seu domínio.

prompt
/replica-skill:replica-entrepreneur

Me mostre as reclamações mais frequentes e o que corrigir primeiro na minha versão.

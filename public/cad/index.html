Peças para impressora 3D só com texto

O SolidCraft é um programa de CAD 3D grátis e de código aberto (licença Apache-2.0). Ele tem um servidor MCP embutido: você conecta no Claude Code, descreve a peça e muda as medidas conversando.

Baixar o SolidCraft
Projeto de terceiros, sem ligação com esta página. O próprio projeto diz que ainda está no começo e serve bem para peças simples: confira as medidas antes de uma impressão longa. Dados conferidos em 03/11/2026.
1

Instale o programa

Baixe para Windows, macOS ou Linux. As versões para Windows ainda não são assinadas: no aviso do SmartScreen, escolha Mais informações e depois Executar assim mesmo.

2

Conecte no Claude Code

terminal
claude mcp add solidcraft -- solidcraft-cli mcp
Se o terminal não achar o comando, use o caminho completo. No Windows, o padrão é C:\Program Files\SolidCraft\solidcraft-cli.exe.
3

Peça a peça

prompt
Usando o SolidCraft, crie um suporte de celular com inclinação de 60 graus, base de 80 x 60 mm e bordas arredondadas. Me mostre as medidas principais e deixe tudo por parâmetros, para eu mudar depois.

Para mudar, é só pedir:

prompt
Muda a inclinação para 45 graus e mantém o resto.
4

Exporte e imprima

prompt
Exporte a peça em STL e em 3MF, e me diga as medidas finais para eu conferir antes de imprimir.

Abra o arquivo no seu fatiador e comece com uma peça pequena.

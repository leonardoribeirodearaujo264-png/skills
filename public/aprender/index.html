passo a passo grátis

Agentes de IA que te ensinam de verdade

O LearnHarness é um app grátis e de código aberto para aprender coisas difíceis. Antes de explicar, os agentes medem onde o seu entendimento acaba. Depois montam o caminho até o seu objetivo, ensinam um passo de cada vez e guardam o que você aprendeu num grafo de conhecimento que a próxima sessão continua.

Baixar o LearnHarness
Projeto de terceiros (amosblomqvist/learnharness, licença AGPL-3.0). Código no GitHub. Esta página não tem ligação com o autor.
1

Instale o app

Baixe pelo site oficial (learnharness.ai) ou pela página de versões do GitHub:

Windows

Rode o instalador. Ele ainda não é assinado, então o Windows pode mostrar o aviso de "editor desconhecido".

Mac

Para Apple Silicon. Arraste o app para a pasta Aplicativos.

Linux

AppImage ou pacote .deb para Debian e Ubuntu.

Baixe só do site oficial ou do GitHub do projeto.
2

Escolha o modelo

Na primeira abertura, você escolhe de onde vem a IA. São três caminhos:

Sua chave de API

De um provedor como Anthropic ou OpenAI. O custo é cobrado pelo provedor, na sua conta.

Claude Code instalado

Em Configurações, Provedores, Claude Code. Usa o login e o plano do seu Claude Code.

Modelo local

Qualquer servidor compatível com a OpenAI, inclusive um rodando no seu computador.

O app não cobra assinatura, mas o uso do modelo tem custo pela sua chave, pelo seu plano ou pelo seu computador. O medidor do app estima só o custo de chaves de API. Ditado e pesquisa na web pedem chaves à parte.
3

Diga o que quer entender

Comece uma sessão dizendo o assunto e o objetivo. Exemplos para enviar:

pedido
Quero entender juros compostos a ponto de calcular sozinho quanto um investimento rende em 12 meses e explicar a diferença para juros simples.
pedido
Quero aprender [ASSUNTO] para [O QUE VOCÊ PRECISA FAZER]. Hoje eu já sei [O QUE VOCÊ JÁ SABE]. Comece medindo o que eu entendo antes de explicar.
pedido
Quero praticar o que aprendi sobre [ASSUNTO] com problemas variados, sem você dizer qual conceito usar em cada um.
4

Como ele ensina

Mede

Pergunta antes de explicar, para achar onde o seu entendimento acaba.

Planeja

Monta o mapa do que você sabe hoje até o objetivo, e você pode ver o plano.

Ensina

Um passo de cada vez: você prevê, recebe a explicação e confere se entendeu.

Pratica

Em sessões à parte, com problemas que se adaptam ao seu raciocínio.

Escreva o que está pensando nos campos de raciocínio: é assim que o agente entende onde está a dúvida, e não só se a resposta está certa. Tudo fica salvo no seu computador.

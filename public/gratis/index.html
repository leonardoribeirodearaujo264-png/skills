guia grátis

Claude Code rodando com modelos de graça

O Free Claude Code fica no meio do caminho entre o Claude Code e o modelo: em vez do Claude pago, ele manda os seus prompts para modelos gratuitos ou para um modelo rodando no seu computador.

Abrir o repositório no GitHub
Projeto de terceiros (Alishahryar1/free-claude-code, licença AGPL v3). Os modelos são de outros provedores, não o Claude da Anthropic, e cada provedor tem os seus limites e regras. Esta página não tem ligação com o autor.
1

Instale

No Windows, abra o PowerShell e rode:

PowerShell
& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))

No Mac ou Linux, no terminal:

terminal
curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh

Quando o instalador perguntar, escolha o Claude Code entre os agentes.

2

Abra o Free Claude Code

  • No Windows e no Mac, abra o atalho Free Claude Code na área de trabalho ou no menu Iniciar.
  • No Linux, rode fcc-server e deixe esse terminal aberto.
  • O painel de administração abre sozinho quando ele liga.
3

Escolha o provedor

NVIDIA NIM

Crie a chave grátis em build.nvidia.com, cole em Providers, NVIDIA NIM, Add key, e clique em Apply.

OpenRouter

Crie a chave em openrouter.ai/keys e escolha um modelo gratuito na lista.

No seu computador

Com Ollama ou LM Studio e uma placa de vídeo decente, o modelo roda local, sem chave.

4

Rode o Claude Code por ele

Em vez de claude, abra o terminal na pasta do projeto e rode:

terminal
fcc-claude

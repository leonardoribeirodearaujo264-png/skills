3 skills grátis

Faça o Claude perguntar antes de errar

O Claude erra o projeto quando sai fazendo sem entender o que você quer. Estas 3 skills obrigam ele a te entrevistar primeiro. Todas são de código aberto, com licença MIT, e os números de instalação são do skills.sh em 09/11/2026.

prompt rápido para o Claude Code
Instale no meu Claude Code estas 3 skills, só dos repositórios oficiais, e me mostre cada comando antes de rodar:
1. interview-me, de https://github.com/addyosmani/agent-skills
2. brainstorming, de https://github.com/obra/superpowers
3. grill-me, de https://github.com/mattpocock/skills
Depois me explique em português quando usar cada uma.
3

Interview Me: 66 mil instalações

Faz uma pergunta por vez, sempre com um palpite junto, até entender quem vai usar, por que você quer aquilo, como é o sucesso e qual é a maior restrição. Serve para pedido vago, do tipo "faz um dashboard".

terminal
npx skills add https://github.com/addyosmani/agent-skills --skill interview-me
2

Brainstorming: 422 mil instalações

Desenha a solução com você, apresenta as opções e só deixa o Claude começar depois que você aprova o desenho. Faz parte do Superpowers, um conjunto de skills de método para programar com IA.

terminal
npx skills add https://github.com/obra/superpowers --skill brainstorming
1

Grill Me: 1,5 milhão de instalações

A mais instalada das 3. Pergunta sem parar sobre cada parte do plano, decisão por decisão, até não sobrar furo. Quando a resposta está no código, ela mesma vai ler em vez de perguntar para você.

terminal
npx skills add https://github.com/mattpocock/skills --skill grill-me
✓

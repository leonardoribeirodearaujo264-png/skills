Vídeos animados com o prompt de cada um

O Prompt Motion é uma galeria de vídeos animados feitos com o Claude. Cada vídeo mostra, do lado, o prompt ou a skill que gerou ele. Tem tela de produto, app de celular, gráfico, diagrama, texto animado, partículas e mais.

Abrir o Prompt Motion
Galeria de terceiros, com curadoria de @p4nthera_. Esta página não tem ligação com o autor. Confira no site as condições de uso de cada prompt.
1

Escolha um vídeo

Use os filtros de categoria (Product UI, Phone, Charts, Kinetic type...) e escolha um vídeo parecido com o que você quer fazer. Abra o vídeo e copie o prompt ou a skill dele.

2

Adapte para o seu produto

Cole o prompt copiado no lugar indicado e envie este pedido ao Claude:

prompt
Vou te passar um prompt de vídeo animado que eu gostei. Recrie o mesmo vídeo para [SEU PRODUTO OU MARCA], com as cores [SUAS CORES] e no formato vertical 1080x1920.
Regras:
- Mantenha a duração, a ordem e o tempo de cada cena do original.
- Troque só o conteúdo: textos, nome, logo e cores.
- Se algo do original não fizer sentido para o meu produto, me diga antes de mudar.

Prompt original:
[COLE AQUI]
Também dá para usar a função Customize do próprio site, que é grátis: você diz para que é o vídeo, o formato e as cores, e ela adapta o prompt.
3

Ajuste o resultado

Depois da primeira versão, peça os ajustes em português:

prompt
Revise o vídeo cena por cena e me diga onde o texto fica difícil de ler no celular. Depois corrija: letras maiores, no máximo 6 palavras por tela e cada cena com pelo menos 1,5 s.
4

Para que serve

Lançamento

Vídeo curto apresentando um produto ou uma função nova.

App de celular

Telas do seu app animadas, sem gravar a tela.

Números

Gráfico animado para resultado, pesquisa ou relatório.

Um estúdio de games no seu Claude

Cinco repositórios do GitHub que cobrem o jogo inteiro: um time de agentes que organiza o projeto, o Claude dentro do editor da Unreal ou da Godot, trilha sonora gerada no seu computador e rosto animado a partir de uma fala gravada. Escolha o motor do seu jogo e siga os passos.

Projetos de terceiros, conferidos no GitHub em 02/11/2026. Esta página não tem ligação com os autores. Confira a licença de cada um antes de usar num jogo comercial.
1

Claude Code Game Studios: o time

49 agentes (diretores, líderes de área e especialistas, do diretor criativo ao testador de QA) e 74 skills para o Claude Code. Licença MIT. Clone como a pasta do seu jogo e abra o Claude Code dentro dela:

terminal
git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git meu-jogo
cd meu-jogo
claude

Dentro do Claude Code, digite /start. Ele pergunta em que ponto você está (sem ideia, ideia vaga ou projeto já começado) e monta o caminho.

Abrir o Game Studios
2

UnrealClaude: o Claude no editor da Unreal

Plugin para a Unreal Engine 5.7 com um painel do Claude dentro do editor e um servidor MCP com mais de 20 ferramentas para atores, Blueprints, fases e materiais. Não vem pronto: precisa compilar para a sua versão da engine. Comece clonando:

terminal
git clone --recurse-submodules https://github.com/Natfii/UnrealClaude.git
Depois siga o README: compilar com o RunUAT, copiar para a pasta Plugins do projeto e rodar npm install na pasta mcp-bridge. A edição de Blueprints ainda tem falhas, segundo o próprio autor.
Abrir o UnrealClaude
3

Godot MCP: o Claude vê os erros do jogo

Abre o editor da Godot, roda o projeto em modo debug, lê a saída e os erros e cria cenas. Licença MIT. Com a Godot instalada, adicione no Claude Code:

terminal
claude mcp add godot -- npx @coding-solo/godot-mcp

Depois peça:

prompt
Rode o projeto Godot desta pasta em modo debug, leia a saída e liste os erros. Para cada erro, mostre o arquivo e a linha, explique a causa e me diga a correção antes de mudar o código.
Abrir o Godot MCP
4

ACE-Step 1.5: a trilha sonora

Gera música inteira no seu computador, de 10 segundos a 10 minutos. Segundo o projeto, leva menos de 10 segundos por música numa placa RTX 3090 e roda com menos de 4 GB de memória de vídeo. Licença MIT. Para Windows e Mac há um pacote portátil no README; pelo terminal:

terminal
git clone https://github.com/ACE-Step/ACE-Step-1.5.git
cd ACE-Step-1.5
uv sync
uv run acestep
Precisa do uv instalado (o README mostra como). Sem placa de vídeo, o próprio projeto indica o site acemusic.ai.
Abrir o ACE-Step 1.5
5

Audio2Face-3D: o rosto que fala

Da NVIDIA: transforma uma fala gravada em animação 3D do rosto, com sincronia da boca (lipsync) e expressão. A página central reúne os modelos, o SDK e os plugins para Unreal Engine 5 e Autodesk Maya.

Cada parte tem a sua licença (o SDK é MIT, os modelos seguem os termos da NVIDIA). Confira na página antes de usar.
Abrir o Audio2Face-3D

prompt

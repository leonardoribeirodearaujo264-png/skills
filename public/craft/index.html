Refaça um site com o Craft Anything

O Craft Anything é um projeto de código aberto, em versão alfa. Você aponta para um site, diz o que quer, e um agente de IA monta um projeto novo, compara com o original e ajusta o que não bate.

Baixar no GitHub
GitHub: github.com/storytold/craft-anything
prompt rápido
Instale no meu computador o Craft Anything do GitHub https://github.com/storytold/craft-anything e me guie no primeiro uso para recriar um site.
1

Tenha o Claude Code no computador

O Craft Anything usa o seu próprio Claude Code, com o seu login, para construir o projeto. Ele precisa estar instalado e conectado antes. O plano gratuito do Claude não inclui o Claude Code, então confira o seu plano.

2

Peça para o Claude Code instalar

Abra o Claude Code e cole este prompt. Ele baixa só do GitHub oficial e pede a sua confirmação antes de baixar e de instalar.

prompt
Instale o Craft Anything no meu computador usando só o repositório oficial: https://github.com/storytold/craft-anything

1. Descubra o meu sistema (Windows, macOS ou Linux) e o tipo de processador.
2. Em https://github.com/storytold/craft-anything/releases/latest, escolha o instalador certo para mim: no Windows o arquivo .msi, no Mac o .dmg.
3. Me mostre o nome e o tamanho do arquivo e espere eu confirmar antes de baixar e antes de instalar.
4. Depois de instalado, rode "craft-anything-cli doctor" e me explique em português o que estiver faltando. Se o comando não existir, me diga como abrir o aplicativo Craft Anything.
3

Ou instale você mesmo

Abra o botão Baixar no GitHub lá em cima e, na lista de arquivos da versão, baixe:

  • Windows: craft-anything-0.5.0-windows-x64.msi. Dê dois cliques e siga o instalador.
  • Mac: craft-anything-0.5.0-macos-universal.dmg. Abra e arraste o app para Aplicativos.

Se aparecer uma versão mais nova, troque o número no nome. Não baixe de outros sites: nomes parecidos não têm ligação com o projeto.

4

Faça o pedido no aplicativo

Abra o Craft Anything, escolha A website, cole o endereço do site, deixe o modo Clean room (o padrão, que não lê o código do site), cole o pedido abaixo e aperte Start.

pedido
Recrie este site com o mesmo layout, cores, fontes e espaçamento, funcionando no celular e no computador. Use textos e imagens de exemplo no lugar dos originais e não copie logo, marcas nem fotos do site.
5

Prefere o terminal?

O mesmo pedido funciona pela linha de comando. Troque o endereço pelo do seu site e rode no terminal; as perguntas aparecem ali mesmo.

terminal
craft-anything-cli rebuild https://seusite.com "Recreate this website"
6

Confira e peça ajustes

Em sites, ele compara a versão nova com o original em três tamanhos de tela, mostra o quanto ficou parecido, lista o que ainda não bate e volta para ajustar. App e jogo também aparecem como opção, mas essa checagem ainda é parcial.

ajuste
Deixe o cabeçalho azul e troque o nome do site por [SEU NOME]. Mantenha o resto igual.
7

Use só no que você pode

Segundo o próprio projeto, ele é para software seu ou que você tem permissão de examinar, e nunca burla DRM, login ou anti-cheat. Para refazer o site de um cliente, peça autorização antes.

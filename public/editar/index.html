passo a passo grátis

O Claude não sabia editar. Agora sabe.

Os vídeos do perfil são feitos assim: o Claude Code escreve cada cena, legenda e animação em código com a skill HyperFrames e entrega o MP4 pronto. Ninguém abre timeline.

1

Instale a skill

No terminal, dentro de uma pasta só para os seus vídeos:

terminal
npx skills add https://github.com/heygen-com/hyperframes --skill hyperframes
Precisa do Node.js. A HyperFrames é um projeto open source da HeyGen (heygen-com/hyperframes, licença Apache-2.0); esta página não tem ligação com o autor.
2

Peça o vídeo

Abra o Claude Code na mesma pasta (claude) e envie:

prompt
Use a skill hyperframes para fazer um vídeo vertical 1080x1920 de 30 segundos sobre [TEMA]. Divida em 5 cenas curtas, com título grande em cada uma, legenda palavra por palavra e animações de entrada. Me mostre prévias das cenas antes de renderizar o MP4 final. Responda em português.
3

Ajuste e renderize

  • Peça mudanças em texto: cor, fonte, tempo de cada cena, o que entra e o que sai.
  • Quando gostar das prévias, peça o render final. O MP4 sai na pasta do projeto.
  • Para narração, grave a sua voz ou use uma voz de IA e peça para ele sincronizar a legenda com o áudio.

passo a passo grátis

A skill que acha as skills por você

A find-skills, do time da Vercel, procura no catálogo aberto de skills, acha as que combinam com a sua tarefa e instala no seu Claude Code. Passou de 4 milhões de instalações no skills.sh.

1

Instale

No terminal, dentro da pasta do seu projeto:

terminal
npx skills add https://github.com/vercel-labs/skills --skill find-skills
Precisa do Node.js instalado. A skill é do repositório vercel-labs/skills; esta página não tem ligação com a Vercel.
2

Peça o que você quer fazer

Abra o Claude Code e diga a tarefa. Exemplo:

prompt
Quero criar conteúdo para o Instagram. Use a find-skills para achar as melhores skills para isso, me mostre as opções com o número de instalações e de onde vem cada uma, e só instale depois que eu escolher.
3

Como ela escolhe

Identifica

Entende a tarefa e busca no catálogo aberto com npx skills find.

Filtra

Prefere skills com muitas instalações e de fontes oficiais.

Instala

Coloca no seu setup com npx skills add.

Skills são instruções de terceiros. Antes de instalar, leia o que cada uma faz.

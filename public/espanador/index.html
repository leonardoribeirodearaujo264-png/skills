pedidos prontos grátis

O Claude Code arruma a sua pasta

Downloads com arquivo repetido, nome estranho e nada que se acha? Abra o Claude Code dentro da pasta e cole os pedidos abaixo, na ordem. Ele separa por tipo, renomeia as fotos pela data, junta PDFs e põe os repetidos numa pasta à parte, sempre mostrando o plano antes de mexer.

Regra de segurança: nada destes pedidos apaga arquivo. Repetidos e dúvidas vão para uma pasta de revisão, e quem apaga é você, depois de conferir. Se a pasta tem algo importante, faça uma cópia antes (passo 1).
1

Abra o Claude Code na pasta e peça o plano

No terminal, entre na pasta que quer arrumar e abra o Claude Code (no Windows, troque o caminho pelo da sua pasta):

terminal
cd ~/Downloads
claude

Depois envie o primeiro pedido. Ele só olha e propõe, não mexe em nada:

prompt
Quero arrumar esta pasta. Antes de mexer em qualquer arquivo, liste o que tem aqui (quantos arquivos de cada tipo, os maiores e os que parecem repetidos) e me mostre um plano passo a passo. Não mova, não renomeie e não apague nada até eu responder "pode seguir". Nunca apague arquivos: o que for descartável vai para uma pasta _revisar.

Se a pasta tem coisa importante, peça uma cópia antes:

prompt
Antes de seguir o plano, copie a pasta inteira para uma pasta de segurança ao lado, com a data de hoje no nome, e confirme que a quantidade de arquivos da cópia é igual à da original.
2

Separe por tipo

prompt
Separe os arquivos por tipo em pastas: Fotos (jpg, jpeg, png, heic), Vídeos, PDFs, Planilhas (xlsx, csv), Documentos (docx, txt), Compactados (zip, rar) e Outros. Só mova, não renomeie. No fim, mostre quantos arquivos foram para cada pasta.
3

Renomeie as fotos pela data

prompt
Na pasta Fotos, renomeie cada foto no formato AAAA-MM-DD_nome-original, usando a data em que a foto foi tirada (dados EXIF). Se a foto não tiver essa data, use a data de modificação e me avise quais foram. Se dois nomes ficarem iguais, acrescente _2, _3. Antes, mostre 5 exemplos de como os nomes vão ficar.
4

Junte PDFs num arquivo só

prompt
Junte os PDFs de contas desta pasta (luz, água, internet, cartão e parecidos) num arquivo só chamado contas.pdf, em ordem de data. Mantenha os PDFs originais. Se precisar de alguma ferramenta para juntar, me diga qual antes de instalar.
Para juntar PDFs, o Claude Code usa uma ferramenta do seu computador (por exemplo, Python). Se ela não estiver instalada, ele vai pedir permissão antes.
5

Repetidos numa pasta à parte

prompt
Ache os arquivos repetidos comparando o conteúdo (hash), não só o nome. Deixe uma cópia de cada no lugar e mova as outras para a pasta _revisar/repetidos. Não apague nada. No fim, me mostre a lista do que foi movido e quanto espaço eu liberaria se apagasse.
6

Confira e só então apague

Abra a pasta _revisar

Olhe o que foi para lá antes de apagar qualquer coisa.

Peça para desfazer

Não gostou? Peça: "desfaça o último passo e devolva os arquivos para onde estavam".

Pasta de trabalho

Use em Downloads, Documentos e fotos. Evite pastas do sistema e de programas.

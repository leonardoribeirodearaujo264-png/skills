Memória para o seu Claude Code

Cada sessão nova do Claude Code começa do zero. O Claude-Mem é um plugin de código aberto que anota o que acontece em cada sessão, resume com IA, guarda num banco no seu computador e devolve o contexto que importa na sessão seguinte. Você explica o projeto uma vez.

Abrir o repositório no GitHub
Projeto de terceiros (thedotmack/claude-mem, licença Apache 2.0). Esta página não tem ligação com o autor. Precisa do Node.js 20 ou mais novo e de uma versão do Claude Code com plugins.
1

Instale dentro do Claude Code

Abra o Claude Code e envie os dois comandos, um de cada vez:

Claude Code
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem

Depois feche e abra o Claude Code de novo. A partir da próxima sessão, o contexto das anteriores aparece sozinho.

Não use npm install -g claude-mem: segundo o próprio projeto, isso instala só a biblioteca, sem o plugin. Pelo terminal, o caminho oficial é npx claude-mem install.
2

A conta online é opcional

O instalador pelo terminal oferece um login no site do projeto, com período de teste do serviço deles. Você pode pular: o próprio projeto documenta a instalação sem conta, e a memória pode usar o seu plano do Claude ou uma chave sua. No Windows (PowerShell):

PowerShell
$env:CLAUDE_MEM_ONLINE_OPTIN="false"; npx claude-mem install
No Mac ou Linux: CLAUDE_MEM_ONLINE_OPTIN=false npx claude-mem install
3

Pergunte ao histórico

Com o plugin ativo, o Claude consegue procurar no que foi feito antes. Exemplos para enviar:

prompt
Procure na memória do projeto o que decidimos sobre [ASSUNTO] e por quê. Cite a sessão e a data. Se não achar, diga que não achou em vez de supor.
prompt
Antes de começar, veja na memória o que ficou pendente na última sessão deste projeto e me diga em 5 linhas por onde continuar.
prompt
Procure na memória se já corrigimos um erro parecido com este: [COLE O ERRO]. Se sim, mostre o que foi feito daquela vez antes de mexer no código.

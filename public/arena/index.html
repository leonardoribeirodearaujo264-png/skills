passo a passo grátis

Quando o Claude errar, bota ele na arena

A Arena Skill pega a sua tarefa e entrega a mesma tarefa, palavra por palavra, para vários subagentes do Claude Code, cada um com uma estratégia diferente. Em duelos, um ataca a solução do outro, os dois se defendem e corrigem a sua, e um juiz dá nota com critérios escritos. O pior sai. No padrão são 100 competidores e 7 rodadas, até sobrar uma resposta.

Abrir o repositório no GitHub
Projeto de terceiros (Jakeschincariol/arena-skill, licença MIT). Esta página não tem ligação com o autor. Precisa do Claude Code e do Python 3.8 ou mais novo. A skill não mexe nos arquivos do seu projeto: tudo fica na pasta .arena/.
1

Instale colando o link

Abra o Claude Code e envie esta mensagem:

Claude Code
https://github.com/Jakeschincariol/arena-skill

Instale esta skill e depois confirme que o /arena funciona.

Prefere instalar como plugin? Envie os dois comandos, um de cada vez:

Claude Code
/plugin marketplace add Jakeschincariol/arena-skill
/plugin install arena-skill@arena-skill
Instalada como plugin, ela aparece como /arena-skill:arena. Instalada pelo link ou copiando a pasta, ela fica como /arena.
2

Use o modo econômico no dia a dia

A skill é grátis, mas cada subagente gasta do seu limite do Claude. O padrão de 100 competidores faz 595 chamadas de subagente. Para o dia a dia, use o --quick: 16 competidores e 91 chamadas.

Claude Code
/arena --quick escreva o título da minha página de vendas

Ou escolha o número de competidores com --agents:

Claude Code
/arena --agents 32 corrija o teste que falha às vezes em tests/test_api.py

--quick

16 competidores, 4 rodadas, 91 chamadas.

--agents 32

32 competidores, 5 rodadas, 187 chamadas.

Padrão

100 competidores, 7 rodadas, 595 chamadas. Guarde para a resposta que importa.

Números do README do projeto (02/11/2026). Antes de começar, a skill mostra quantas chamadas vai fazer.
3

Dicas para dar certo

Tarefa clara

Os subagentes não veem a sua conversa, só o arquivo da tarefa. Tarefa vaga gera 100 respostas vagas.

Menos perguntas de permissão

Cada subagente grava um arquivo em .arena/. Rode no modo de aceitar edições (Shift+Tab) para não aprovar um por um.

Confira o vencedor

O juiz também é o Claude. Você recebe a resposta que sobreviveu e os ataques que ela aguentou: leia antes de usar.

Os Mods do Claude Code

Um mod muda como o Claude Code funciona e o que ele mostra: um painel ao lado da conversa, um comando novo, uma regra que entra antes de cada ação. Você não precisa programar: descreve o que quer e o próprio Claude escreve o mod. Abaixo estão os três usos do vídeo, com o pedido pronto de cada um.

Conferido na documentação oficial do Claude Code em 10/11/2026.
1

Confira a versão

Os Mods vêm ligados a partir da versão 2.1.287 no terminal e 2.1.286 no app do Claude para computador.

No terminal

Rode claude --version. Se for mais antiga, atualize o Claude Code.

No app

Numa sessão da aba Code, digite /status e veja a linha Claude Code.

2

Como pedir um mod

Abra uma sessão normal do Claude Code e descreva o mod com as suas palavras. Quando o Claude salvar o primeiro arquivo, ele pergunta se pode ligar a recarga automática: aceite e o mod passa a funcionar no fim da resposta. Se ele não usar o caminho certo, digite /plugin-authoring antes do pedido.

Um mod pode ver tudo o que acontece na sessão, aprovar ações e gastar o seu uso. Peça mods para você e não instale mod de quem você não confia.
3

Uso 1: sessões que conversam

Uma sessão do Claude Code pode mandar mensagem para outra. Com um mod, você deixa a troca visível e passa o plano de uma para a outra com um comando:

prompt
Faça um mod com um painel ao lado da conversa que mostre as mensagens que esta sessão manda e recebe das minhas outras sessões, com a hora de cada uma. Crie também o comando /passar, que manda para a sessão que eu escolher um resumo do plano combinado aqui, com a lista de tarefas, para ela construir.

Na prática: uma sessão planeja, você usa /passar, a outra constrói e responde quando terminar.

4

Uso 2: um painel só seu

O mod desenha um painel dentro do próprio Claude Code. Este mostra o que os seus agentes estão fazendo:

prompt
Faça um mod com um painel chamado "Seus agentes" ao lado da conversa. Para cada subagente que começar nesta sessão, mostre o nome, o que ele está fazendo agora, há quanto tempo está rodando e se terminou. Atualize o painel a cada mudança e guarde a lista do dia mesmo se eu fechar e abrir a sessão.
5

Uso 3: tarefa fácil no modelo mais barato

Um mod pode mandar um pedido para outro modelo antes de ele sair. Assim as tarefas simples param de comer o seu limite:

prompt
Faça um mod que mande para o modelo Haiku os pedidos simples, como renomear arquivos, traduzir um texto curto, resumir um log ou formatar uma lista, e deixe todo o resto no modelo atual. Mostre sob cada resposta qual modelo respondeu. Crie o comando /desvio para eu ligar e desligar a regra, e comece desligado.
Comece com poucos tipos de pedido e confira as respostas. Se um pedido difícil cair no modelo menor, a resposta piora; aí é só ajustar a regra com o próprio Claude.
6

Guarde o mod para sempre

O mod que o Claude escreve vale só na sessão em que ele nasceu e some depois de um tempo. Para usar em toda sessão, peça:

prompt
Copie a pasta do mod que você criou nesta sessão para ~/mods/ e me diga como carregar ele nas próximas sessões.

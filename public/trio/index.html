Context Mode: menos lixo na conversa

Toda ferramenta que o Claude Code usa despeja o resultado bruto na conversa (página inteira, log, lista de issues) e isso come o seu limite. O Context Mode guarda esse material fora da conversa e deixa entrar só o que importa. No exemplo do próprio projeto, 315 KB viram 5,4 KB.

Abrir mksglu/context-mode

Dentro do Claude Code, envie um comando de cada vez:

Claude Code
/plugin marketplace add mksglu/context-mode
/plugin install context-mode@context-mode

Reinicie o Claude Code e confira se está tudo certo:

Claude Code
/context-mode:ctx-doctor
/context-mode:ctx-stats
O ctx-stats mostra quanto você economizou na sessão. Licença Elastic 2.0: uso livre, com algumas restrições para quem quer revender como serviço.
2

Auditoria de segurança da Cloudflare

A skill transforma o seu agente num auditor: ele mapeia o projeto, procura falhas e manda cada falha encontrada para um agente novo que tenta provar que ela é alarme falso. Só o que sobrevive vira relatório.

Abrir cloudflare/security-audit-skill

No terminal, dentro da pasta do seu projeto (precisa do Node.js):

terminal
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit

Depois abra o Claude Code na mesma pasta e peça:

prompt
Faça uma auditoria de segurança deste projeto e salve o relatório na pasta auditoria. No fim, me explique em português simples as falhas confirmadas, da mais grave para a menos grave, e o que corrigir em cada uma.
A auditoria usa vários agentes em paralelo e gasta bastante do seu limite. Rode em um projeto seu e corrija com calma. Licença MIT.
1

VoiceStudio: estúdio de voz no seu computador

Alternativa grátis e de código aberto à ElevenLabs: clona voz, cria voz a partir de uma descrição, dubla vídeo, dita e transcreve, tudo rodando no seu computador.

Abrir debpalash/VoiceStudio

No Windows, baixe o instalador na página de versões do projeto (Releases) ou, no PowerShell:

PowerShell
irm https://voicestudio.sh/install.ps1 | iex

No Mac, com o Homebrew:

terminal
brew tap debpalash/tap
brew install --cask debpalash/tap/voicestudio
Clone só a sua própria voz ou a de alguém que autorizou. Usar a voz de outra pessoa sem permissão pode ser crime e é contra a regra do próprio projeto. Os modelos de voz têm licenças próprias, que o app mostra antes de baixar. Licença do app: AGPL-3.0.

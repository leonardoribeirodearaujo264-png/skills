passo a passo grátis

Um time de engenharia no seu Claude Code

O ECC (Everything Claude Code) é um projeto grátis e de código aberto com 71 agentes, 314 skills e 98 comandos para o Claude Code. Tem agente que planeja, que revisa código, que procura falhas de segurança e que cuida dos testes. Também funciona no Codex, no Cursor e no OpenCode.

Abrir o repositório no GitHub
Projeto de terceiros (affaan-m/ECC, licença MIT). Instale só pelo repositório oficial: o próprio autor avisa que cópias não oficiais podem trazer vírus. Esta página não tem ligação com o autor.
1

Instale com dois comandos

Abra o Claude Code na pasta do seu projeto e digite, um de cada vez:

dentro do Claude Code
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
Depois, abra uma sessão nova e rode /plugin list para ver o ecc@ecc ativo. Instale de um jeito só: se usar o plugin, não faça também a instalação manual, senão as skills ficam duplicadas.
2

Peça o plano antes do código

O agente planejador monta o passo a passo da função antes de qualquer linha de código:

prompt
/ecc:plan "Adicionar login com Google"
3

Revise segurança e testes

Antes de publicar, peça a revisão de segurança e confira a cobertura de testes:

prompt
/ecc:security-scan
/ecc:test-coverage

Planejar

O agente planner desenha a função inteira antes do código.

Segurança

O security-reviewer audita o app com a lista OWASP Top 10.

Testes

O fluxo de TDD escreve o teste primeiro e mira 80% de cobertura ou mais.

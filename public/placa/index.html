Sua placa roda IA pela metade

O GPU Unlock é um projeto de código aberto (licença GPL-2.0) de Zagitta. Ele retira o limite de velocidade dos núcleos que fazem as contas de IA nas placas GeForce, antes do driver da Nvidia carregar. Não usa driver modificado nem mexe na BIOS.

Abrir o GPU Unlock no GitHub
Projeto de terceiros, sem ligação com esta página nem com a Nvidia. Ele instala um módulo no sistema e altera a inicialização do Linux: faça por sua conta e risco. Dados conferidos em 03/11/2026.
1

Confira a sua placa

Funciona só no Linux. A série RTX 30 é a estável. As séries RTX 20 e RTX 40 ainda são experimentais. A série RTX 50 não é suportada. O ganho é em IA: em jogos não muda nada.

Na RTX 3090 Ti, o teste do projeto foi de 88 para 157 TFLOPS (+80%). Em uso real, o próprio projeto cita de +25% a +55% em LLM e de +30% a +55% em geração de imagem.

2

Instale

No terminal do Linux:

terminal
git clone https://github.com/Zagitta/gpu-unlock
cd gpu-unlock
make install

Depois acrescente gpu_unlock.targets=all na linha de comando do kernel, mantendo as opções que já existem, e reinicie. O README explica como fazer em GRUB, Fedora, systemd-boot e UKI.

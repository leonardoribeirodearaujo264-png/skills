Ache a falha antes do hacker

A Strix é uma IA de pentest open source: em vez de entregar uma lista de bugs possíveis, ela solta um time de agentes que atacam o seu app de verdade, confirmam cada falha com uma prova e sugerem a correção. Roda no seu computador, com Docker e a chave de um modelo de IA.

Projeto de terceiros (usestrix/strix, licença Apache-2.0, mais de 70 mil estrelas), conferido no GitHub em 10/11/2026. Esta página não tem ligação com os autores. A Strix é grátis; o modelo de IA que ela usa é cobrado pelo provedor da sua chave.
1

Antes de começar

Docker

Instale o Docker Desktop e deixe ele aberto. Na primeira vez a Strix baixa a imagem onde os testes rodam.

Chave de um modelo

Uma chave de API de um provedor aceito (OpenAI, Anthropic, Google, OpenRouter e outros). A lista está na documentação da Strix.

2

Instale

No Mac e no Linux:

terminal
curl -sSL https://strix.ai/install | bash

No Windows, instale o WSL (o Linux dentro do Windows) e rode este comando e os próximos dentro dele.

3

Configure o modelo e rode o primeiro teste

Troque o modelo e a chave pelos do seu provedor, no formato da documentação. Depois aponte para a pasta do seu app:

terminal
export STRIX_LLM="[PROVEDOR/MODELO]"
export LLM_API_KEY="[SUA CHAVE]"
strix --target ./pasta-do-seu-app

Também dá para testar o app no ar ou um repositório: strix --target https://seu-app.com. Os resultados ficam na pasta strix_runs.

Teste só o que é seu ou o que você tem autorização por escrito para testar. Atacar sistema de terceiros sem permissão é crime. Prefira um ambiente de teste a produção.

4

Pelo Claude Code

A Strix tem skills prontas para o Claude Code rodar o teste e corrigir as falhas. Instale na pasta do seu projeto:

terminal
npx skills add usestrix/strix

Depois peça:

prompt
Use a Strix para fazer um teste de segurança neste projeto, que é meu. Quando terminar, me mostre cada falha confirmada em linguagem simples: o que é, onde está, a prova e o risco. Proponha a correção de cada uma e só mude o código depois que eu aprovar. No fim, rode o teste de novo para confirmar que as falhas sumiram.

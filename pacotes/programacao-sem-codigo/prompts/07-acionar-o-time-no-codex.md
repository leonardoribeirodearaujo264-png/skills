# Acionar o time pelo líder no Codex

Use no Codex. Lá o agente só entra em ação quando é citado pelo nome no pedido.

```text
lider-projeto, conduza este pedido:
[DESCREVA O QUE VOCÊ QUER, EM LINGUAGEM COMUM]

Me entreviste, monte o plano em linguagem simples e espere meu sim.
Para cada etapa aprovada, cite pelo nome o especialista certo: arquiteto-de-solucao para estrutura, desenvolvedor para implementar, testador para conferir e revisor-de-seguranca antes de publicar.
Só me entregue o que passou no teste e na revisão.
```

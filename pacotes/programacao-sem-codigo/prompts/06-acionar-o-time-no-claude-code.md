# Acionar o time pelo líder no Claude Code

Use no Claude Code quando o pedido for maior que uma correção rápida e você quer o time inteiro trabalhando.

```text
Use o agente lider-projeto para conduzir este pedido:
[DESCREVA O QUE VOCÊ QUER, EM LINGUAGEM COMUM]

O líder deve me entrevistar, montar o plano em linguagem simples e esperar meu sim.
Depois, uma etapa por vez: arquiteto-de-solucao quando houver decisão de estrutura, desenvolvedor para implementar, testador para conferir e revisor-de-seguranca antes de publicar ou quando tocar em login, dados ou pagamento.
Só me entregue o que passou no teste e na revisão.
```

# Criar um time novo com a skill

Use quando a sua empresa tem uma área sem time, como jurídico, RH, compras ou logística.

Claude Code:

```text
Use a skill montar-time-de-agentes para criar um time de [ÁREA] para a minha empresa. Me entreviste antes de criar, me mostre a lista de agentes e espere o meu OK. Crie cada agente nos dois formatos, Claude Code e Codex.

Minha empresa: [O QUE VOCÊ VENDE E PARA QUEM]
O que mais toma tempo nessa área hoje: [TAREFAS]
```

passo a passo grátis

Claude Code com modelos de graça

A FreeLLMAPI junta os planos gratuitos de 34 provedores numa conta só: cerca de 7,4 bilhões de tokens por mês e 635 modelos. Quando um modelo bate o limite, ela passa para o próximo da fila e avisa o modelo novo do que já foi feito.

Abrir o repositório no GitHub
Projeto open source de terceiros (tashfeenahmed/freellmapi, licença MIT). O próprio autor avisa que é para uso pessoal e testes, não para produção, e que as regras de cada provedor continuam valendo. Os modelos são os gratuitos desses provedores, não os modelos pagos da Anthropic. Esta página não tem ligação com o autor.
1

Instale

No Windows, o caminho mais fácil é o instalador .exe da página de Releases. No Mac há o .dmg.

Baixar a versão mais recente

Se preferir servidor com Docker, rode no terminal (o script está publicado no site do projeto para você ler antes):

terminal
curl -fsSL https://freellmapi.co/install.sh | bash
2

Cadastre as chaves grátis

  • Abra o painel. No servidor ele fica em http://localhost:3001; no app de desktop, pelo ícone da bandeja em Open Dashboard.
  • Na página Keys, adicione as chaves gratuitas dos provedores que você quiser usar. Cada provedor tem o próprio cadastro.
  • Em Fallback Chain, arraste os modelos na ordem de preferência. É essa fila que ele segue quando um limite acaba.
  • Copie a chave unificada que aparece no topo da página Keys.
3

Ligue no Claude Code

O gerador do projeto ajusta a configuração do Claude Code e faz backup antes. Rode primeiro com --dry-run para ver o que vai mudar:

terminal
npx freellmapi setup-claude --url http://localhost:3001 --api-key SUA_CHAVE_UNIFICADA --dry-run
npx freellmapi setup-claude --url http://localhost:3001 --api-key SUA_CHAVE_UNIFICADA

Depois é só abrir o Claude Code normalmente. Para voltar aos modelos da Anthropic, desfaça a configuração pelo backup que o gerador criou.

4

O pulo do gato

Troca sozinha

Quando um provedor bate o limite, o pedido vai para o próximo da sua fila.

Nota de passagem

Com o context handoff ligado, o modelo novo recebe um aviso de que está continuando a tarefa de outro.

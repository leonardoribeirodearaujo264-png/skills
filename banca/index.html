Monte uma banca para o seu código antes de publicar

Três jurados que já vêm no Claude Code: um caça bugs, um caça falhas de segurança e um limpa o que ficou repetido. Rode os três antes de subir qualquer coisa para produção.

1

Antes de chamar a banca

  • Atualize o Claude Code com claude update. Os comandos abaixo aparecem quando você digita / no chat.
  • Abra o Claude Code na pasta do projeto, com as suas mudanças ainda não publicadas.
  • Se usar Git, faça um commit antes. Assim você vê exatamente o que cada jurado mudou.
2

Jurado 1: bugs

Revisa o que você mudou e aponta erros de lógica, casos esquecidos e o que vai quebrar.

Claude Code
/code-review
3

Jurado 2: segurança

Procura senha e chave escritas no código, dados expostos e entrada sem validação.

Claude Code
/security-review
Se ele achar uma senha ou chave no código, não basta apagar a linha: troque a senha ou gere uma chave nova, porque a antiga pode já estar no histórico.
4

Jurado 3: limpeza

Revisa o código alterado atrás de repetição, complicação desnecessária e desperdício, e aplica as correções.

Claude Code
/simplify
5

O veredito

Depois dos três, peça um resumo único:

prompt
Junte o que a banca encontrou em code review, security review e simplify. Dê um veredito só, APROVADO ou REPROVADO para produção, liste o que falta corrigir em ordem de gravidade e corrija o que for seguro corrigir agora. Responda em português.

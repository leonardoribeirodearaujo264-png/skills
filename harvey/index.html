Harvey: o agente do Claude Code que arruma cliente

Ele procura empresas que combinam com o seu negócio, lê o site de cada uma, escreve um e-mail personalizado e leva a conversa até a reunião. Todo e-mail espera a sua aprovação antes de sair.

Abrir o repositório no GitHub
O Harvey é um projeto open source de terceiros (ethanplusai/harvey, licença MIT). Esta página só explica como instalar e não tem ligação com o autor.
1

O que você precisa

  • Python 3.11 ou mais novo.
  • Assinatura Claude Pro ou Max, com o Claude Code logado. Ele usa a sua assinatura, sem conta de API.
  • Uma caixa de e-mail para enviar, de preferência num domínio secundário, separado do seu domínio principal.
  • Aquecimento dessa caixa de e-mail antes do primeiro envio, para não cair no spam.
2

Baixe e abra no Claude Code

No terminal, rode:

terminal
git clone https://github.com/ethanplusai/harvey.git
cd harvey
claude
3

Peça a configuração

O repositório já vem com instruções que transformam o Claude Code num assistente de instalação. Ele confere o que falta, instala, pergunta o que precisa e aprende sobre o seu produto. Envie:

prompt
set up Harvey for me

Quando terminar, o painel fica em localhost:5555, com o funil inteiro ao vivo.

4

Antes do primeiro envio

Você aprova tudo

Cada e-mail fica na caixa de saída até você aprovar.

Você é o remetente

Siga as regras de e-mail frio e da LGPD e mantenha a opção de descadastro que ele já coloca.
